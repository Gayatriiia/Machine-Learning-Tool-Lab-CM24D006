How Transfer Learning Works
01

Feature Extraction

MobileNet's convolutional layers act as a frozen feature extractor — outputting a 1024-dim embedding for any image.

02

Sample Collection

You hold objects in front of the camera and add labelled examples. Each frame → MobileNet → embedding vector stored.

03

KNN Classifier

Instead of fine-tuning, a K-Nearest Neighbour classifier compares live embeddings to stored examples by cosine distance.

04

Live Inference

Every frame is classified in <16 ms. Confidence bars show class probabilities from KNN vote counts.
